# Pesalo Features

Pesalo is a passkey-first savings wallet on Stellar. You hold **USDC, EURC, and XLM**, every dollar starts earning the moment it arrives, and you can lock in higher rates when you want certainty.

This section walks the user-facing surfaces. The [Developer](/developer/architecture) section covers how each one is built.

## What's on testnet

Pesalo runs on **Stellar testnet** today. Wallet creation uses Face ID / a passkey where available; on simulators or unprovisioned devices we fall back to a random Stellar keypair stored in the device secure enclave so the rest of the app works end-to-end. See [Limitations](/features/limitations) for the testnet-specific quirks.
